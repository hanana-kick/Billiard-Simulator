## Boundaries that must not be hidden

- All native results above use Linux llvmpipe software WebGPU. They do not establish macOS Chrome/Metal compatibility or hardware performance.
- Exact original pure `wide` and `divideWide` bodies are fused; scene-dependent divide variants remain scalar. Pure helper outputs are exact, but conservative instruction charges and slice-tail fragmentation can fail sooner than the old scalar implementation. The same total work ceiling is not an identical budget-failure boundary.
- CPU normalized trace equivalence is not a full raw 4 MiB trace CPU oracle. Existing raw strike/contact-interior collector limitations remain.
- Same-runtime width switching, shared cache lifetime, final frontend resource accounting, actual final-build browser tests, Korean font verification, full app integration and production deployment are unfinished.
- The completed-pipeline cache source is preserved but its integration is not qualified by these runs.
- No native/browser test was launched for this backup itself. No Actions workflow was dispatched. The commit uses `[skip ci]`; exact remote head and Actions absence must be verified separately.
