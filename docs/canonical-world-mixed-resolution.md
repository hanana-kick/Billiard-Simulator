# Supported-prefix chronological resolution

A coarse whole-prefix box overlap is not itself an impact. The world-only resolver retains the original accepted SMT2 input/output descriptor before rebase, queries every pair/static/cloth boundary on that original time parameter, and uses a pair response only after the separate entering qualification succeeds. No fake directional representation, constant-acceleration reinterpretation, or last-pair-ID suppression is used.

If the refined query proves the entire original prefix clear, its endpoint may be committed without a collision. If a pair is qualified, every body's original full p/v/q is sampled at the same impact clock, the unchanged full 3D contact solve changes only the involved pair, and the state is rebuilt at that common clock. The journal captures the commit before the solved-pair marker is released. A separating or mixed landing prefix is then evaluated before another supported query. Unsupported bridge/rolling descriptors or unqualified overlaps remain pending.

The world schedule now repeats the mixed-prefix stage where needed rather than assuming only one initial landing. Initial externally supplied FLIGHT is still pending82. Explicit iteration limits are checked on GPU, so parking a mixed commit does not grant extra prefix iterations. The first committed pair's diagnostic entry/response are retained; later no-op phases cannot overwrite them.
