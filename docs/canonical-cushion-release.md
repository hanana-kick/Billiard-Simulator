# Owned finite-cushion outward release

`deterministic-cushion-release.mjs` proves a whole accepted motion prefix leaves
one just-committed finite cushion. It is not a last-object exemption. The full
original mixed-motion query still checks all balls, other hulls/statics, cloth and
regime limits. Only the selected owned hull record can be replaced by this proof.

## Owned source

The source is the world immediately after `commitMixedCushionWorldCPU` (or its
resident mirror): cushion counter61 is nonzero, its commit clock62 equals both the
world clock5 and prefix origin8, and receipt63 identifies body/verified rail. Every
descriptor's admitted kind, ID, mass, radius, original time, and complete p/v/q
must match that successful world (status1); rolling/bridge source modes cannot
borrow a supported descriptor's release authority. The actual hull identity/bounds must match the immutable scene/rail map.
After any elapsed-time commit this origin test fails; old contacts cannot grant
future hull exemptions. The request owner must snapshot these buffers.

## Proof, independent of nearest-feature changes

At the exact committed center, the actual convex-hull query supplies a uniquely
qualified nearest-point normal interval and lower distance d0. Let B enclose the
maximum distance of any center in the entire accepted prefix from that center.
Require d0>B>=(0). Then all centers remain outside the convex hull.

Projection onto a closed convex set is nonexpansive; its residual is likewise
nonexpansive. Normalizing that residual changes its direction by at most
2B/(d0−B). The implementation uses the more conservative component pad
4B/(d0−B), outward-rounded and capped at2. This bounds normals even if the nearest
face/edge/vertex changes during the prefix. No constant-feature assumption is made.

The interval dot product of these normals with the supplied original velocity
bounds must be strictly positive. Independently, for SMT2, the exact normalized
position-polynomial derivative d+2c(t/h) must have strictly positive dot product.
The latter is essential: the separately encoded velocity polynomial is not the
exact derivative of the position polynomial after coefficient rounding. The
proof does not substitute one for the other. It evaluates the original duration
and coefficients, with directed rational arithmetic; extreme unsupported derivative
coefficients are refused, never clipped.

Finally an actual endpoint hull query, enlarged by the original endpoint position
receipt, must be strictly separated by more than the ball radius. Every other
ledger record must prove clear for the same whole prefix. A work failure, stale
origin, another collision, non-outward derivative, uncertain normal or insufficient
end separation remains pending. No contact or gameplay event is generated by a
release, and no global carried physical enclosure is claimed.

The proof is for the declared canonical-local dense motion and its local numerical
receipts. It is not a claim that the approximate simulation exactly reproduces
real-table physics. The caller retains original local accuracy/deadline/work
budgets and advances all bodies from their original descriptors at the same end
clock only after `released:true`.

## Resident stages

- Index0: original descriptor rows, world scene, [horizon,maxNodes], full query1056.
- Index1, in hull order0..3: rows, actual hull, query, source world256, immutable
  rail map16, [horizon,maxNodes,maxInitialPenetrationQuanta,hullIndex,staticCount],
  proof64. Hull0 initializes the proof; only the owned selected hull evaluates it.

Five dispatches, no intermediate readback. The standalone runner returns only the
query/proof diagnostics. The proof does not alter the physical journal or advance
world state itself; the owning world must commit the already-admitted full endpoint.
