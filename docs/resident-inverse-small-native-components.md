the individual body hashes, complete shader hashes, and original source-file

`v8-13.6.233-fast-hypot-binary64-v1` profile, not an assertion about other JS

planning measurement, not proof that a driver will compile or execute it.

## Inputs and independent comparison

`resident-candidate-inverse-component-prepare.mjs` uses the existing
`resident-candidate-inverse-query-initial-fixture.mjs` and authenticated original
registered prestrike snapshot. It keeps original initial admission/clearance,
request identities, topology, raw parameter words and source rule settings.

* **Authentic observation lane:** unchanged original `LabInverseEvents.begin`
  and `advance(...,1)` execute the complete original first outer step (64 inner
  h, no source cap reduction). The component retains only the initial and first
  four after-world/before-application frames, including real original contact
  impulses and collider `projectPoint` results. All retained observation fields
  are checked against the original live observer at the exact cut. This is
  captured input to a reducer test, not a GPU world producer.
* **Declared discrete observation lanes:** ordered hits, simultaneous ambiguity,
  closest relative chord and signed zero are consumed by both the unchanged
  original observation methods and generated source. They are explicitly not
  physical trajectories.
* **Declared discrete terminal witnesses:** the exact fixture helper formerly
  private to `resident-candidate-inverse-query-join.mjs` is shared, without
  changing its logic. Original physical accumulator decisions and original
  `projectResult` supply the independent expected fields. Accepted records match
  all 64 words (256 bytes), including residuals, inequalities, purpose, nullable
  cell, Number bits, identity and reserved words. Late foul remains a negative
  physical-stop decision; a positive witness is not a reached full-rest shot.
* Status/protocol corruptions are compared against the independent strict ABI
  packer in all 64 words, not only a pass flag: unfinished, unsupported,
  cancellation, failure, creation, clearance, sequence, cell, full-rest bit,
  raw identity, missing observation, mismatch, event index and availability.
  Mutation is lane 0 only; lane 1 must still equal the original source result.
* Reducer order/frame corruption changes only its explicit failed header;
  derived overflow agrees with the original nonfinite rejection. Projection
  retains `round(-0)`, handles `.5` exactly, and rejects `2^53`/Infinity without
  leaking scalar authority. A padded invocation is inert in every dispatch.

The mapped join uses the **full** real `tip-impact-128-192` composition layout:
254,024 audit/checkpoint words, observer at 254,080, 2 × 2,496 observer words,
259,072 total words (1,036,288 bytes). The entire dirty audit/checkpoint/alignment
prefix, each observer prefix, original world bank and raw input views must stay
bit-identical. The exact original scalar source is recoverable by undoing only
the checked logical-view mapping. No emission-only replacement or larger
logical source view is substituted. This allocation is a qualification fixture,
not a compact production memory estimate.

## Bounded transport and resource estimate

* 4 shaders; 26 independent component jobs; **32 fixed dispatches**.
* 4 reducer lanes, 5 captured observation frames, 2 extra negative/projection
  jobs; 23 two-lane audited join scenarios.
* 35,542,260 bytes uploaded; 35,749,044 bytes copied to readback buffers;
  **71,291,304 bytes total owned device buffers**, excluding driver pipelines.
* One command submission. Reducer intermediate checkpoints are device COPY
  commands only; every map happens after the final submission. No CPU state
  continuation, source physics fallback or result-dependent scheduling.
* HOST preparation observed about 11–13 seconds and 620–680 MiB peak RSS in
  this container. The optional worker imports only Node built-ins and a lean
  GPU owner, not original physics/oracles/source generators. GPU compilation,
  driver memory and runtime are deliberately unestimated until measured.

All shader `getCompilationInfo()` checks finish before any pipeline is created.
Pipelines are serial, descending exact closure bytes (heavy first). No runtime
buffers or dispatches are created by `--compile-only`. Validation/pipeline/device
failure has no fallback and disposes owned resources. Native admission requires
an explicitly reviewed entire-artifact SHA-256 and unchanged source hashes.

## Commands

HOST only (requires the same original fixture and prepared local engine as the
existing initial fixture; no optional skip/fabricated replacement):

```sh
node --test --test-concurrency=1 \
  tests/resident-candidate-inverse-components.mjs \
  tests/resident-candidate-inverse-query-join.mjs
node tests/resident-candidate-inverse-component-worker.mjs \
  --prepare /tmp/inverse-native-components.v8
node tests/resident-candidate-inverse-component-worker.mjs \
  --validate /tmp/inverse-native-components.v8 SHA256_FROM_PREPARE
```

Preparation writes a combined **HOST-only precursor**. It is never a native
input. Split it without another original capture:

```sh
node tests/resident-candidate-inverse-component-worker.mjs \
  --split /tmp/inverse-native-components.v8 SHA256_FROM_PREPARE \
  /tmp/inverse-small
```

This writes three physically separate, closed files and a manifest:

* `.plan.v8`: small shaders, exact schedules, buffer word counts, source/runner
  hashes and input digest; **no buffer words or expected fields**.
* `.inputs.v8`: upload words only, exact job names and source/payload hashes.
* `.expected.v8`: assertion-only final/checkpoint/compact expected words, bound
  to the exact plan/input and native/assertion runner hashes.

The native role imports neither preparation nor assertion/original-oracle
modules. It opens only the small plan during validation/compilation. All four
compilation-info checks and heavy-first pipelines finish **before** the 35 MB
input payload is opened. A compile-only receipt records zero buffer allocations,
zero dispatches and `inputOpened:false`, `expectedOpened:false`. No native role
opens expected words, including for comparison. After a real execution it
writes an actual-only artifact, with plan/input/source/runner identities and
explicit invocation ID. A separate assertion process opens expected and actual.

Only after the parent grants the serialized native slot (not executed here):

REQUIRE_WEBGPU=1 node tests/resident-candidate-inverse-component-runtime.mjs \
  --compile-only /tmp/inverse-small.plan.v8 PLAN_SHA \

## Reserved-identifier successor

`inverse-observation-reducer.mjs` changes only scoped WGSL `active` →
`pairActive` and `target` → `targetPoint`. Reversing these names recovers the
entire previous source module/shader bytes. All four compiled HOST VM
instruction arrays and unchanged helper body hashes match the predecessor.
Only the observe shader grows by 59 bytes; the project and both terminal join
shaders remain byte-identical. No equation, case, cap, ordering or expected
Number word changes. The original source frame capture is not repeated.

`resident-candidate-inverse-component-alpha-repair.mjs` authenticates the exact
predecessor, verifies every numerical input/expected Uint32Array byte and
case/schedule hash, then replays all 26 jobs/32 steps and compares 8,937,261 words.
The new source/hash/runner/plan envelopes legitimately have new file digests;
expected-word hash remains
`5ba3e6ef2d30a11d052a7750b952f07ad8f466dc1811ed49a3af2262f56e8cd4`.
The native preflight now gathers all four compilation-info error sets before
throwing, still with zero pipelines/allocations/input opens on any error.
The reserved-identifier regression explicitly demonstrates that the HOST scalar
parser accepts the old names and therefore cannot replace the native WGSL gate.
