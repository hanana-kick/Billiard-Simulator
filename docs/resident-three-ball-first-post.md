## Exact entry and endpoint

`createThreeBallFirstPostPlan(firstSpherePlan)` accepts only the local original
initial chain. `executeThreeBallFirstPostForTest(plan,{testOnly:true})` has no
state, timestep, expected-result, geometry, callback or continuation input.
It extends the private sphere path at the original boundaries:

1. Actual cue owner completes before genuine-three sphere solve/writeback.
2. For each awake sphere, execute the unchanged-equation lifecycle post-fat
   graph **before its sphere post-CCD check**. The fat input contains current
   canonical solved translation, original radius/margins/static bounds and
   current pre-solve fat bounds from the already-owned HOST geometry input.
   No expected future fat box is admitted. Retained floor topology is required.
3. Gather the solved body into its existing floor cache. Compare the complete
   144-word payload, not merely impulses, to the actual original leased
   `Floor.solvePrepared` result. Compare all post-fat bounds separately.
4. After **all** dynamic bodies' actual inactive postchecks, execute original binary64
   `angularPatchResistance` program ordering, then the native f32 torque cast
   and matrix application. Read current normal/impulse/body fields and original
   application constants; do not use a source result to choose eligibility.
5. Use the existing exact scene `postApplication` enqueue kernel in original
   object order. Even an eligible zero torque marks the body mutable, matching
   the original API. Complete the scene application phase only after all three
   actual object iterations, required fat steps and CCD checks.

The shared numerical solver owns the admitted disconnected floor components.
No pair/cushion/cue-contact solve is added. Canonical cue rows remain3/4, with

The separate original source path uses the still-leased floor results, original

## Original Number versus compensated arithmetic

`experimental-angular-patch.js` has distinct factories. The explicitly used
`createSourceDoublePostWorldStage` calls `sourceReference`, which uses ordinary
JS Number operations and `Math.hypot`. `createReferencePostWorldStage` instead
uses the approximately48-bit compensated graph; it is not used here. No default
factory or old four-ball emitted program is changed.

The tests also call the **actual**
`PhysicsLab.prototype.angularPatchResistance`, using the unchanged `LabMath`
helpers and actual native `RigidBody.applyTorqueImpulse`. Four bounded nonzero
mixed-spin, low-speed, pure-spin and pure-roll component inputs compare exact
binary64 torque bits and native f32 angular bits. Native world stepping is
explicitly prohibited by the witness. These are component-boundary inputs, not
claims of physically reachable shots or independent whole-h parity.
