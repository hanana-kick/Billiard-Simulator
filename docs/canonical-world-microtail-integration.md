# Resident world microtail and diagnostic integration

The canonical-local world recurrence now routes an admitted sub-Q20 cloth-flight
cluster through the genuine microtail adapter before ordinary landing/support
advancement. The adapter retains all-body p/v/q and the original absolute shot
clock. A successful microtail commit is journalled once, then parked for the rest
of that iteration; it is not a fabricated REST event. Rejected/competing geometry
remains pending. A component iteration is still charged; cumulative physical-event
and work-budget certification is not claimed.

Composite cloth journal events retain their bounded impact count, clock bracket,
and rational flight time in the auxiliary sidecar. CPU and GPU whole-world
results return `journalAuxWords`. Ordinary landing explicitly clears composite
metadata before capture, so a later ordinary landing cannot reuse an old sidecar.

The world landing packet chooses the gravity-derived velocity representative
limit only when no explicit limit was supplied. This changes the admitted clock
packing domain, not the root bracket, endpoint equations, or root precision.
`prepareCanonicalWorldContinuation` validates and freezes an optional
`maxVelocityCorrectionQuanta` (1..4096); explicit stricter limits remain effective.
Legacy component defaults remain unchanged.

`createCanonicalWorldContinuationGPU(device, binding, {strikeBackend})` forwards
an explicit immutable `staged` or `chunked-16` raw producer selection. Default is
still `staged`. The 2026-10-27 backend checkpoint verified 11,888 literal words
across 18 executed candidates, strict no-kiss clear-shot REST, failures, budgets,
pre/post-submit cancellation and reuse. This is software Vulkan correctness
and timing evidence, not physical-GPU throughput or release certification.

compact result). It commits pair tick 73720, six ordinary landings, a two-impact

Faster shots may still stop pending at the next rolling event; finite cushion

Passing this nominal canonical-local REST fixture is not a global physical-
enclosure certificate, full-game release, or general hardware timing claim.
