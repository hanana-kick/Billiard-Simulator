# Recurring rigid-cue contact exclusion

The reference and actual-WGSL guard pass four tests against untouched native collider queries. The original three-ball created pose and independently observed h1 pose each have 54 filter-compatible cue/obstacle pairs and no native query contact. Both backends also reject independently native-positive tip/cloth, shaft/cloth and other-ball/shaft fixtures. The minimum admitted separating residual is 0.023838548m at creation and 0.023805408m at h1. This gate tests geometry admission, not a simulated trajectory.

The guard is a conservative prerequisite for the disconnected cue-joint/ball-floor solver, not a contact solver or collision-equivalence claim. It retains actual analytic cylinders and spheres, cuboid dimensions, and the original serialized convex point order. Cylinder support extent in direction d is halfHeight·abs(d.y) + radius·sqrt(d.x²+d.z²). Box support uses its three half-extents; convex support scans the original vertices. No capsule, polygon cylinder, substituted bounding box, inferred triangle topology or future contact oracle is used.

Each call transforms the original collider local translations by the owner's current body quaternion and position. It attempts separating support intervals along world and both collider-local basis directions. A proven separating interval suffices; failure to find one is explicitly unsupported, not a claim of collision. The exact source collision groups exclude passive pair colliders and native tip/ball contacts. The surviving roster is shaft and neck versus 16 statics and three primary balls, plus tip versus 16 statics: 54 pairs. Custom sphere-tip impulses remain a separate stage.

The source prediction margin is f32(normalized_prediction_distance × length_unit), currently 0.00006150000263005495m. A further conservative 0.0001m exclusion band protects the bounded f32 projection calculation. Thus some valid separated poses can be rejected; the band never weakens a native comparison or changes CPU physics. Supported positions are finite native f32 within ±10m; quaternion norm error is below2e-5; original identity collider-local rotations, zero contact skins/soft-CCD prediction, rigid shapes and source filters are required. Unsupported filters, changed roster, generation mismatch, omitted geometry, extreme values or unproved separation fail closed.

API: createReferenceGuard({created,roles,sceneRegistry}), createGpuGuard(device,initial), isGuard(guard,backend), and guard.check({cue:{shaft,head},balls:[{body,translation,rotation,radius},...]}). Initial geometry is cloned once. Dynamic check inputs are only current own states. The common owner must call it before committing each collision/solve transaction; the h1 oracle in the test is never an implementation seed. The module does not step a native world. No per-frame native geometry/cache data is accepted.

This is an endpoint, static exclusion test, not a continuous sweep or active-CCD implementation. The common owner separately retains its source-inactive CCD guards. Any emerging rigid contact that cannot be excluded stops the bounded solver rather than silently omitting a contact row. Whole cue clearance, general collisions and full-shot parity remain unclaimed.
