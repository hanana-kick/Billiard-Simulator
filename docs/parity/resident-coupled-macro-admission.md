# Optional coupled transport macro: admission only

Adds **id3 `rc_coupled_transport_advance`**, six original u32 arguments to one
u32 source return. Selection is explicit:

```js
compileMicrocodeWGSL(source, {
  entry,
  externalFunctions: ['rc_coupled_transport_advance'],
});
// Pass the resulting externalFunctions metadata through unchanged.
generateMicrocodeExternalWGSL({ ...vmOptions, macroId: 3 });
```

No caller's existing explicit three-macro list is changed. Omitting
`externalFunctions` keeps scalar source lowering. The current fixed world
runtime admission is not extended here; this registry addition is neither
runtime activation nor device/whole-world qualification.
