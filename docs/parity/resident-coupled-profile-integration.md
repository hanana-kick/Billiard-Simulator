## HOST reference and cost boundary

The new TEST callback compiles the canonical id3 closure to ordinary scalar
microcode with `intrinsics:'none'` and unchanged source arguments. It uses no
new approximation or special-case physics result. The already existing harness
bound remains256×65536 scalar instructions per complete call; exhaustion throws
as test incompleteness, never miss/pass. Captured actual calls required68,66,47
chunks respectively, with source returns0,0,1. The reference additionally rejects
a sixth argument other than32768 under this fixed profile before source writes.

Moving source work into a HOST callback does not eliminate its arithmetic.
The historical created-HOST run reached h191 in1,806.5 seconds and674,724,316 core
steps; the known final segment contains11,748,617 coupled-body steps. A new
fresh HOST h192 proof is therefore still potentially **tens of minutes**, not a
GPU-like subsecond calculation. This is an order-of-work estimate from the old
execution, not a measured new duration or a deadline. Core counters in the new
profile exclude the callback's internal scalar instructions; report them with
macro counts, not as total work saved. No new replay was started here.
