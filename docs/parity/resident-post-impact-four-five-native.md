## Observed costs

All times are host wall intervals; queue drain is **not a GPU timestamp**.
Both profiles used fallback SwiftShader on the same cloud environment, under a
coordinator quiet hold, but **different fresh processes/devices** in fixed
four-then-five order. There was no randomized/ABBA or hardware calibration.
Each profile retained only its pipelines across its two fresh-buffer passes.
