# Bounded actual cue stroke continuation

The bounded, altered-layout single-ball centered horizontal strike continuation is verified against the unchanged original engine on both the scalar reference and actual WGSL. This is not full-engine or full-shot parity.

`experimental-cue-stroke-stage.js` is a privately branded, transactional pre-world stage. It imports neither the lifecycle owner nor a native oracle. `prepare(ownBallState)` proposes ball velocity changes and holds the cue's next state privately; `commit()` accepts that state only after the ball world, CCD and post-world angular phases succeed. `abort()` discards it. It does not accept per-frame native cue state.

The source ordering is lateral head/shaft impulse, compliant single-sphere tip law, separation removal, native preparation/activation, common-h constraint solving, solved-motion CCD, and original angular-patch law. On the first separation h the lateral prefix still runs, but cue rows do not: the original application removes head, shaft and fixed guide before `world.step`. The current trajectory fixture stops after that first fully completed separation h. It does not pretend that cue removal changes the already captured 64-substep h midway through an outer application step.

The source model's tip collider and sphere collider do not collide because their mutual collision-group filters reject the pair. Their interaction is the original pre-world compliant impulse, not a substituted native contact. Cue joints act on shaft/head, while floor rows act on the selected ball and fixed cloth. Those dynamic constraint components are disconnected only while every other native cue/environment contact is absent and global CCD remains inactive. All awake bodies may nevertheless share one active solver island. Factoring these source components under the same h and 12/4/1 solver schedule is not a general split-world simulation.

The fixture uses unchanged `PhysicsLab.step`, observing each original post-angular endpoint. After the constructor's own 72 native settling steps, the fixture explicitly removes the other two balls, moves the selected ball to x=.4 and executes 72 additional application steps. Original static table/cloth/cushions, true ball sleep/CCD flags and mass-zero passive pair collider are retained. Physical equations and descriptors are unchanged, but the dynamic scene and selected placement are deliberately changed. The clearance-checked centered horizontal speed-2 strike uses the original 0.012 m retraction; it is not the product-default 8-degree strike or a three-ball scene. A single snapshot is taken after the first actual approach h. Thus GPU strike creation/first-insertion preprocessing remains outside this continuation gate. No tip teleport or shortened artificial approach is used. Default h is 1/61440 s, approximately 0.016276 ms; the continuation bound is 20 ms and must actually contain approach, compression and separation.

Native `get_mut` operations queue bodies even when a later zero-impulse guard leaves velocity unchanged. The pre-stage reports ordered head/shaft/ball/head mutable calls, nonzero-impulse strong-wake flags, and pre-solve cue body state. The activation owner must preserve serialized body IDs, ordered queues, timer/history and active-set epochs. ImpulseJointSet assembly/selection epochs and several workspaces are serde-skipped and cannot be inferred from a snapshot. The cue numerical stage rebuilds rows every h and does not claim reconstruction of those native persistent caches.

Pinned source attribution: Rapier b716d375efc0201003f0cd9ef7168eee0b62c177, Apache-2.0, especially `rigid_body.rs`, `rigid_body_set.rs`, `pipeline/user_changes.rs`, `island_manager`, and `physics_pipeline/substep.rs`; application law/order in this repository's `src/physics.js`. Active CCD, coupled cue rigid contacts, general BVH evolution, full native cache restoration and post-separation full-shot rest are not established by this component.

Current admission is intentionally restricted to the original-coefficient, altered-layout single-ball centered horizontal speed-2 fixture, zero cue user-force/torque, and matching ball radius. It does not admit arbitrary elevation, offset, placement or environment and does not provide a general recurrent cue-clearance guard. The unchanged native fixture verifies the absence of every additional solver contact at every h. First-contact/last-contact times and episode/removal events are compared; peak force, maximum compression and accumulated `lastStroke.normalImpulse` statistics are not yet reconstructed.

## Verified trajectory

The combined gate passes 12/12 without skips: seven prepared activation/ownership cases and five cue-continuation checks. The unchanged application produces 446 original h, 7.259114583333334 ms, including 76 touching h and actual separation/removal. From the one post-first-h snapshot, each candidate backend advances its own remaining 445 h without subsequent native body, row or contact injection. Both reach the same first/last contact times, one contact episode and cue removal. Accumulating the original h yields 7.259114583333313 ms in the private elapsed counter; original application world time is compared exactly.

Maximum absolute numeric residual is 1.7347234745631684e-19 for both scalar and actual WGSL. The comparison retains 53 signed-zero differences and 19 subnormal differences on scalar, and 54 signed-zero differences and 16 subnormal differences on WGSL. These counts include all compared numeric fields, not distinct physical events. This is fixed-tolerance agreement, not universal bit identity. WGSL executes through Dawn/Vulkan software WebGPU with storage-buffer readback; this is not a hardware performance or all-device guarantee.

Selected ball position/quaternion limits remain 1e-6; component velocity and cue pose limits remain 3e-6, with joint/native impulse limit 2e-6 and the existing cloth-cache criteria. Every endpoint of this single-ball/cue fixture compares live body handles/generations, types, enable/change flags, native IDs and joint adjacency, activation scalar fields, ordered queues, epochs, persistent island membership and lifecycle events exactly. Sleep pose history uses the existing 2e-6 bound. The first fully completed separation h is the stopping boundary, not physical rest.

## Independent reference integrity

The reference is captured once for both backends and stored in a Node/V8-versioned, hashed binary preserving negative zero. Original application/math/engine, fixture/exporter/decoder hashes, engine revision, initial snapshot hash, payload hash and lengths are checked before reuse. Candidate implementation hashes are recorded separately and cannot change during a run. Plain diagnostic JSON is not a raw zero-sign oracle.

Rapier's public SdpMatrix3 result aliases its shared scratch buffer. Reading rotation or another getter before copying that matrix can corrupt an observation without changing native physics. The fixture copies all nine matrix values immediately and independently compares them with typed serialized effective_world_inv_inertia at every h. The regression also demonstrates that delayed reading of the same native view is different. At the first two original h, immediate and serialized diagonal values are 12590.1357421875; delaying until after rotation overwrites the early entries with quaternion data. The original failed observation is preserved separately; no candidate equation, CPU physics, tolerance or expected theoretical mass was substituted to fix it.

Rerun with REQUIRE_WEBGPU=1, GPU_NATIVE_MODULE and RAPIER_SNAPSHOT_DECODER configured, using node --test --test-concurrency=1 on tests/experimental-awake-activation.cjs and tests/experimental-cue-stroke-continuation.cjs. The fixture creates its checked reference only if absent. CUE_STROKE_REPLAY_V8 selects a pre-existing verified artifact and refuses missing or incompatible data rather than silently recapturing.
